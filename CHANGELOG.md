# Changelog

All notable changes to this project will be documented in this file.

The format follows the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses semantic versioning where practical.

## [1.0.0] - 2026-05-06

### Added

- Initial Vue 3 and Vite dashboard application.
- Historical BNM Kijang Emas local JSON dataset.
- ASB dividend local JSON dataset.
- Ar-Rahnu / pajak emas simulation controls.
- Gold value calculation using buying price per gram.
- Pawn margin, storage fee, restructure proceeds, net surplus, redemption cost, and total cashflow logic.
- Detailed restructure table.
- Summary comparison table.
- Investment comparison against ASB and Fixed Deposit.
- Chart.js visualization for gold value, pawn balance, storage fee, and net surplus.
- Responsive dashboard layout.
- Cloudflare Pages deployment support.
- Portfolio-quality README, contribution guide, project structure guide, MIT license, and changelog.

### Documentation

- Added professional GitHub README.
- Added MIT license.
- Added contribution guidelines.
- Added recommended project structure documentation.
- Added repository description and suggested GitHub topics.
